# Clatterhaul — Content & 10-Hour Pacing Plan

**Version:** 2.0  ·  **Owner:** Lead & Systems Designers  ·  Source of R1-DEPTH-2 / R1-LOOP-1 resolution

> Goal: design — not assert — a **≥10-hour** experience with a deliberate fun curve, an unlock cadence that always dangles the next carrot, and "reasons to return" beyond the credits. Times assume a 3-player group at average skill; solo/duo scale via assists, 4-stacks via chaos.

## 1. Macro structure

```
6 BIOMES × (3–4 Contracts + 1 Boss-Haul)  →  first full clear ≈ 6.0–6.5 h
           ↓ unlocks feed ↓
ENDLESS "The Long Haul" + DAILY GAUNTLET + WORKSHOP + MASTERY  →  +4–6 h and ongoing
```

## 2. Hour-by-hour first-playthrough curve (Contracts mode)

| Hour | Beats | New toys / hooks | Emotion target |
|---|---|---|---|
| **0:00–0:20** | **The First Hill** guided haul (Canyon outskirts). Teaches grab, station, call-outs. | Wheels, Flatbed, Winch; ping & emote wheels | "Oh no — hahaha — we did it!" |
| **0:20–1:00** | Canyon Contracts 1–2 (ravine winching, mud). | Crane-arm; first cosmetic; Scrip intro | competence + first disaster clip |
| **1:00–1:30** | Canyon Contract 3 + **Boss-Haul: The Collapsing Mesa**. | Outriggers; Rank 2; Glacier unlock | first big triumph |
| **1:30–2:30** | Glacier Contracts (ice friction, crevasses) + Calamity "The Calving." | Skis, Ballast; Sprockets currency intro | mastering a new physics |
| **2:30–3:30** | Swamp/Mire (bog, gas pockets) + Calamity "Gator Alley." | Paddle-wheel, Balloon | improvisation under pressure |
| **3:30–4:30** | Volcano/Cinder (heat zones, falling rock) + Calamity "The Avalanche of Cinders." | Heat-shielding cosmetic, Rocket-puff | high-stakes speed |
| **4:30–5:30** | Neon City (traffic, electrified rails) + Calamity "Neon Rush Hour." | Mono-wheel, decals | comedic chaos peak |
| **5:30–6:30** | Sky-Ruins (wind gusts, floating gaps) + **finale Boss-Haul: The Last Span**. | Gyro, prestige cosmetic; credits | epic send-off |

**End of Contracts (~6.5h):** the toolbox is full, all biomes unlocked for Endless/Daily, prestige opens.

## 3. Reasons to return (the +4–6h and beyond)

| System | What it adds | Cadence |
|---|---|---|
| **Daily Gauntlet** | one shared seed+mutators/day, leaderboards | daily, ~10–15 min/run |
| **Foreman's Challenges** | 3 daily + 3 weekly objectives (e.g., "finish a haul with 0% payload loss in the Glacier") | daily/weekly |
| **The Long Haul (Endless)** | escalating mutator chains; personal bests | session-length, infinite |
| **Mastery: Perfect Hauls** | per-contract S-tier (no payload loss, under par time) | completionist |
| **Blueprint Garage + Workshop** | build, save, share, download contraptions | creative, infinite |
| **Union Ranks & cosmetics** | rank-up rewards, prestige paint/hats | steady drip (doc 12) |
| **Seasonal drops** (post-launch) | new biome/cargo/mutators free | quarterly (doc 17) |

## 4. Unlock cadence (carrot map; full tables in doc 12)

- **First 20 min:** 1 module + 1 cosmetic (instant "taste" — R2-ECON-8).
- **Every contract:** Scrip payout → 1 meaningful unlock choice.
- **Every Boss-Haul:** a class-defining module or new biome.
- **Every rank:** cosmetic + occasional mutator card.
- **Rule:** the player can always *see* the next unlock and is ≤ 1–2 hauls from it (avoids grind/empty extremes — R2-DIFF-6).

## 5. Difficulty & mastery curve

- **Onboarding:** First Hill + contextual coaching (doc 15); safe routes default.
- **Self-selected difficulty:** each leg offers **safe/slow vs risky/fast** route forks; Endless/Daily layer **opt-in mutators** that multiply score.
- **Mastery ceiling:** Perfect Hauls, par times, Daily leaderboards, prestige.
- **Assists (no stigma):** sticky-grab, co-pilot auto-balance, slower hazards (doc 16) keep solo/duo and mixed-skill crews in the fun zone (R3-FRUST-2).

## 6. Session shapes

| Group time budget | Recommended mode |
|---|---|
| 15 min | Daily Gauntlet (1 run) |
| 30–45 min | 2–3 Contracts or 1 Endless run |
| 60–90 min | a full biome + Boss-Haul, or a deep Endless |

## 7. Content inventory at launch (for scope tracking; build plan doc 03)

- 6 biomes × (3–4 Contracts + 1 Boss-Haul + 1 signature Calamity) ≈ **22 hand-tuned hauls + 6 Boss-Hauls + 6 Calamities**.
- ~40 modules, 12+ cargo types, ~16 mutator cards, 60+ cosmetics, 8 emotes, Daily/Endless generators.
- All reuse one physics loop + asset-store art → high content-per-dollar (the cost thesis).
