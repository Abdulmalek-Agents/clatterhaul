# Clatterhaul — UX / UI & Onboarding

**Version:** 2.0  ·  **Owner:** UX/UI Designers  ·  Source of R1-ONB-11 / R2-UX-10 / R3-ONB-6 resolution

> Principles: **diegetic-first, minimal in chaos, deep in the Garage.** A new player is hauling within 60 seconds; a veteran has a full creative toolbox.

## 1. HUD (in-haul, minimal)
- **Payload condition** (diegetic gauge + small icon), **distance-to-goal** ribbon, **strain** shown first by the rig itself (creak/sparks) then a subtle UI pip.
- **Ping wheel** (hold-to-open radial: "here/danger/help/go/wait") and **Emote wheel** (8 emotes).
- Voice indicators (who's talking), teammate nameplates with role tag (Steer/Crane/etc.).
- Contextual interact prompt (one button). HUD auto-fades when calm; respects HUD-scale & high-contrast options (doc 16).

## 2. Onboarding — "The First Hill" (≤ 60s to fun)
- Guided Canyon micro-haul: prompts teach **grab → board a station → call it out → winch → celebrate**.
- Contextual coaching only when needed (e.g., "the rig is tipping — someone hop on the outrigger").
- **Role suggestion** on first real run so a 4-stack isn't lost (R3-ONB-6); **co-pilot assist** auto-balances for solo/duo.
- Skippable for veterans; never blocks a friend who joined to "just play."

## 3. Menus & screens
| Screen | Contents |
|---|---|
| **Main** | Play (Contracts/Endless/Daily/Free), Garage, Cosmetics, Challenges, Options, Replays |
| **Lobby** | Steam invite, ready-up, crew preview, biome/mutator pick, blueprint select |
| **Garage (Blueprint editor)** | snap-grid build, module palette by class with trade-off readouts, test-drive bay, save/share, paint/cosmetics |
| **End-of-run Story Card** | route map, payload condition, Scrip/Sprockets, rank progress, Perfect-Haul status |
| **Blooper Reel** | auto montage of 3 biggest disasters + Save/Share |
| **Replay Theater** | scrub host-recorded buffer, free-cam, one-click clip/GIF export |
| **Photo Mode** | filters, FOV, googly-eye toggle, frame, hide-HUD |
| **Leaderboards** | Daily Gauntlet (global/friends), Endless bests |

## 4. Blueprint editor UX (depth without intimidation)
- Snap-grid with ghost-preview, mass/balance meter, "will it tip?" stability hint, one-click symmetry, templates for newcomers, and a test-drive bay before depart.

## 5. Controls
- **Gamepad** (primary): move, grab (one button), interact/board, ping (hold), emote (hold), camera, jump/clamber.
- **KB/M** fully supported & remappable. Context-sensitivity keeps the button count low.

## 6. Readability under chaos (R3-CLARITY-5)
Strict HUD budget; danger cues are diegetic + colorblind-safe; voice & ping always cut through; never more than a few UI elements on screen during a haul.

## 7. End-of-session hook
Story Card → Blooper Reel → "Next contract is 1 haul from a new module" nudge → "one more haul."
