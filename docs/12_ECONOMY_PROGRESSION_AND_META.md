# Clatterhaul — Economy, Progression & Meta

**Version:** 3.0 (Cycle-2)  ·  **Owner:** Economy/Progression Designers

> Golden rule: **all power is a sidegrade.** Progression sells identity, variety, and goals — never advantage. Concrete numbers (payout formula, XP curve, par times, assists) now live in **Balance & Tuning (doc 26)**; module stats in **doc 21**.

## 1. Currencies
- **Scrip** (soft, frequent): from every haul → modules, basic cosmetics, mutator cards.
- **Sprockets** (rare): Boss/Perfect Hauls, weekly challenges, rank milestones → premium cosmetics, prestige paints, blueprint slots.
No real-money core currency; optional cosmetic DLC is direct-purchase (doc 17).

## 2. Union Ranks
20 ranks, each grants a guaranteed toy (cosmetic/module/mutator). After 20: **Prestige** ("Master Tinker") — cosmetic-only resets. XP curve & per-haul XP: **doc 26 §4**.
| Band | Drip |
|---|---|
| 1–5 | core modules + starter cosmetics |
| 6–12 | class-defining modules, first mutators, emotes |
| 13–20 | cosmetics, blueprint slots, prestige |

## 3. Modules (sidegrade matrix)
40 modules defined by trade-off vectors; no all-biome "meta" build; each biome has counter-vectors. Full datasheet + guardrails: **doc 21**. QA tracks pick/clean-rate per build per biome (doc 27).

## 4. Cosmetics (long-tail)
60+: paints, decals, horns, flags, hats, googly-eyes, outfits, emotes, voices, nameplates, trophies. Drive identity/flex — the retention engine — with zero balance impact.

## 5. Goals layer
Foreman's Challenges (3 daily/3 weekly) · Perfect Hauls (0% loss + ≤par + no module lost; doc 26 §3) · Daily Gauntlet leaderboards (cosmetic frames) · ~40 funny Steam achievements.

## 6. Unlock pacing
First session ≥ 3 unlocks ≤ 30 min; median time-to-next-unlock ≤ 20 min during Contracts; cosmetic-only chase post-campaign. Telemetry re-tunes if > 25 min (doc 26 §6).

## 7. Anti-power-creep & fairness
Modules = sidegrades; perks = opt-in situational; mutators = opt-in score multipliers (cap ×2.5). Mixed-rank crews keep capability parity.

## 8. Telemetry
Scrip/hour, time-to-unlock, module pick-rates, cosmetic equip-rates, challenge completion, prestige rate → data-driven re-balance (doc 06).
