# Clatterhaul — The First 90 Minutes (new-player beat sheet)

**Version:** 3.0  ·  **Owner:** UX + Lead Designers  ·  Resolves C2-R1-ONB-6, C2-R2-LAUGH-1

> The first session decides the review and the wishlist-to-refund line. This maps the new-group experience minute-by-minute, with explicit **hook checkpoints**: first laugh, first clip, first unlock, first triumph. Target: by minute 90 the group has cleared a Boss-Haul, unlocked 4–5 toys, shared ≥1 clip, and said "one more."

## Hook checkpoints (must-hit)
| By minute | Hook |
|---|---|
| 0:02 | in a lobby with a friend (Steam invite, one click) |
| 0:06 | first physics laugh (a wobble/ragdoll in the tutorial) |
| 0:12 | first "we did it together" (First Hill cleared) |
| 0:18 | first unlock (a module + a cosmetic) |
| 0:25 | first Disaster-Cam clip auto-saved |
| 0:45 | first real failure — framed as funny, not punishing |
| 1:15 | first Boss-Haul attempt |
| 1:30 | Boss-Haul cleared → new biome unlocked → "one more" |

## Minute-by-minute

### 0:00–0:06 — Boot & lobby (frictionless)
- Launch → main menu → "Play with Friends" → Steam invite. Host picks **Contracts**.
- Loading tips set tone (Foreman one-liners). Crew spawns in **The Depot** hub; can run, grab junk, emote immediately (toy-first).

### 0:06–0:12 — The First Hill (guided, ≤ 6 min)
- Contextual prompts teach, in order: **move → grab a crate → board the steering station → someone winch → call it out (ping/voice) → crest the hill → celebrate**.
- Designed first laugh: the rig wobbles on the crest; a ragdoll or two; Disaster-Cam primes (subtle). Foreman: "Wheels on. Brains optional."
- No fail state here; it's a confidence builder.

### 0:12–0:20 — First payout & unlock
- Story Card: route, payload intact, **+300 Scrip**, Rank progress. Garage opens: spend Scrip → **first module (Crane-arm) + first cosmetic (a hat)**. Equip & test-drive.
- Teaches the meta loop in < 3 min; the carrot is visible (next unlock 1 haul away).

### 0:20–0:45 — Canyon CN-2 & CN-3 (first real hauls)
- Real hazards (ravine winch, mud, falling rock) but generous checkpoints. Crew learns triage (more jobs than hands).
- **First Calamity** (Rockslide Run) inside CN-3 — telegraph → panic → relief; designed clip moment.
- Expect the **first real failure** here — framed funny: gravestone card ("Here lies the cheese…"), Blooper snippet, instant retry from checkpoint. No progress lost, lots of laughs.

### 0:45–1:15 — Mastery ramp
- Repeat/finish Canyon contracts; rank to 2; unlock **Outriggers**; a Foreman's Challenge appears ("finish a haul with the cheese intact").
- Group settles into roles by preference (role-suggestion nudge for 4-stacks). Solo/duo get co-pilot auto-balance.

### 1:15–1:30 — First Boss-Haul: The Collapsing Mesa
- 3 readable stages (winch up → balance tilt-plateau → ramp-launch). Tension peak of the session; Disaster-Cam + triumphant stinger on clear.
- Reward: **+900 Scrip, +1 Sprocket, Glacier unlocked**, a trophy cosmetic. Foreman: "Cargo intact?! Mark the calendar."

### 1:30 — The "one more" beat
- End screen previews Glacier (new physics!) and the next unlock 1 haul away. Blooper Reel offers Save & Share. The group says "one more." — funnel complete.

## Solo / duo path notes
- Co-pilot assist auto-stabilizes an empty station; sticky-grab on; hazards slightly slower (doc 26). The same beats land at a calmer pace.

## What QA verifies (cases in 27)
- ≥ 80% of new groups reach CN-BOSS within 90 min (first-session funnel).
- First laugh by ~6 min; ≥ 5 laughs in the session (Laugh Audit, doc 06).
- Zero "unfair" failures; every failure offers instant, lossless retry.
